What the demonstration excludes

Unsupported star alleles, CYP2D6 copy-number variation and hybrid alleles, phase ambiguity, assay coverage, drug-mediated enzyme inhibition/induction (phenoconversion), and genotype-to-phenotype rules for CYP2C9, CYP3A5 and SLCO1B1.

A phenotype is not a drug-specific recommendation. This site uses a static local ruleset, not an automatically updated CPIC database.

Source references: CPIC CYP2D6 · CPIC CYP2C19. Consult the current CPIC diplotype tables before any clinical use.
